# Developer Cheatsheets

Welcome to the **Cheatsheets Directory**. This module offers concise, high-yield reference cards, syntax summaries, time/space complexity matrices, and everyday CLI recipes for quick recall.

---

## Directory Navigation

```text
Cheatsheets/
├── DSA/  # Big-O complexity charts, common STL/Python method complexities, algorithmic pattern decision trees
├── SQL/  # Clause execution orders, window function cheatsheets, join visual maps, date-time format recipes
└── Git/  # Everyday workflow commands, branch management, interactive rebasing, merge conflict resolution
```

---

## Category Highlights

### 1. [DSA Cheatsheets](./DSA/)
- **Big-O Complexity Lookup**: Best, average, and worst-case time & space complexities for standard sorting algorithms and data structure operations.
- **Data Structure Method Complexities**: Time complexity lookup for Python (`list`, `deque`, `set`, `dict`), C++ STL (`vector`, `map`, `unordered_map`, `priority_queue`), and Java (`ArrayList`, `HashMap`, `TreeSet`).
- **Algorithm Selection Matrix**: When to apply BFS vs DFS, Dynamic Programming vs Greedy, Two Pointers vs Sliding Window.

---

### 2. [SQL Cheatsheets](./SQL/)
- **Query Execution Order**: `FROM` / `JOIN` → `WHERE` → `GROUP BY` → `HAVING` → `SELECT` → `DISTINCT` → `ORDER BY` → `LIMIT` / `OFFSET`.
- **Window Functions Cheat Sheet**: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, `NTILE()`, and frame clauses (`ROWS BETWEEN ...`).
- **Join Decision Tree**: Visual guide for `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, and `CROSS JOIN`.

---

### 3. [Git Cheatsheets](./Git/)
- **Branching & Stashing**: Quick commands for branching, switching, stashing changes, and cherry-picking commits.
- **History & Inspection**: Visual log formatting, tracking file history across renames, and diffing branches.
- **Undo & Recovery**: Safely undoing commits (`git revert` vs `git reset`), reflog recovery, and discarding uncommitted modifications.
